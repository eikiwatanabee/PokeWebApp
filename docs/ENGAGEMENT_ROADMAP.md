## Phase 1: 毎日使いたくなる仕組み（習慣化）

### 1.1 コミットストリーク 🔥
**目的**: GitHubの草と同じ心理で「途切れさせたくない」を生む

- 連続コミット日数をトラッキング
- ストリーク表示（🔥 3日連続！）
- ストリークボーナスXP（7日: x1.5倍, 30日: x2倍, 100日: x3倍）
- ストリーク凍結アイテム（土日用に週1回使える）
- ストリーク途切れ防止のプッシュ通知（Slack/Discord Webhook）

### 1.2 デイリーチャレンジ 📋
**目的**: 毎日ログインする理由を作る

- 日替わりチャレンジ（例: 「今日3コミットで追加XP」「レビューを1つ書こう」）
- 達成でボーナスXP + レアアイテム
- チャレンジの種類:
  - コミットチャレンジ: 「N回コミット」
  - コラボチャレンジ: 「他人のPRをレビュー」
  - 品質チャレンジ: 「テスト付きPRをマージ」

### 1.3 ウィークリーミッション 📅
**目的**: 週単位の目標でモチベーション維持

- 週替わりの大きな目標（例:「PR5本マージ」）
- 達成で特別なポケモン（レア枠）をゲットするチャンス
- 進捗バーで可視化

## Phase 2: ポケモンをもっと面白く（コレクション欲）

### 2.1 レアリティシステム ⭐
**目的**: 「次は何が出るか」のワクワク感

| レアリティ | 確率 | 対象 |
|---|---|---|
| ⬜ Common | 60% | 一般ポケモン |
| 🟩 Uncommon | 25% | 2段階進化済み |
| 🟦 Rare | 12% | 最終進化形 |
| 🟪 Epic | 2.5% | 伝説ポケモン（フリーザー等） |
| 🟨 Legendary | 0.5% | 幻のポケモン（ミュウ等） |

- ストリークボーナス中はレア確率UP
- 図鑑のレアリティ別表示
- レアゲット時の特別演出

### 2.2 ポケモン進化システム 🔄
**目的**: XPを使う目的を作る（稼ぐだけでなく使う）

- ゲットしたポケモンにXPを注いで進化させられる
- フシギダネ → フシギソウ（100 XP消費）→ フシギバナ（300 XP消費）
- 進化させたポケモンはプロフィールに飾れる

### 2.3 図鑑コンプリートボーナス 📕
**目的**: 長期的な目標設定

- 地方別の図鑑（カントー151匹、ジョウト100匹...）
- 各地方コンプでメダル + タイトル獲得
- タイプ別コンプ（ほのおタイプ全種など）でボーナス

### 2.4 お気に入り & パートナーポケモン 💕
**目的**: 愛着を持たせる

- 1匹を「パートナー」に設定
- パートナーはプロフィールアイコンの横に常時表示
- パートナーと一緒にコミットした日数で特別なバッジ

## Phase 3: ソーシャル要素（競争と協力）

### 3.1 バトルシステム ⚔️
**目的**: ポケモン集めに戦略的意味を持たせる

- ユーザー同士の自動バトル（ポケモンのタイプ相性ベース）
- 週間バトルランキング
- 自分のポケモンパーティ（6匹）を編成
- バトルで勝つとバトルポイント → 特別報酬

### 3.2 ポケモン交換 🔄
**目的**: コミュニケーションのきっかけ

- チーム内でポケモン交換リクエスト
- ダブり（同じポケモン）を交換に出せる
- 交換成立で双方にボーナスXP

### 3.3 チームレイドイベント 🏟️
**目的**: チームで協力する大きな目標

- 月1回のレイドボス（例: ミュウツー）
- チーム全員のXP合算で倒す（目標値に到達すれば撃破）
- 撃破で全員に限定ポケモン
- レイド期間中はチーム内のコミットが可視化

### 3.4 リーダーボード拡充 📊
**目的**: 比較と競争の楽しさ

- 週間/月間/全期間の切り替え
- カテゴリ別（コミット数、PR数、レビュー数）
- テナント内ランキング + グローバルランキング
- ランキング変動通知（「3位に浮上！」）

## Phase 4: 通知とフィードバック（リテンション）

### 4.1 Slack / Discord 連携 🔔
**目的**: アプリを開かなくてもエンゲージ

- ポケモンゲット通知をSlackチャンネルに投稿
- レベルアップ通知
- ストリーク危険通知（「今日まだコミットしていません🔥」）
- 週間サマリー（今週のXP、ゲットしたポケモン）

### 4.2 GitHub プロフィール連携 🏷️
**目的**: 外部での自慢要素

- README用のバッジ生成（レベル、ポケモン数、ストリーク）
- GitHub Profile README に貼れるSVGバッジ
- 例: `![PokeGitHub](https://pokegithub.app/badge/username.svg)`

### 4.3 アチーブメントシステム 🏅
**目的**: マイルストーンの達成感

| アチーブメント | 条件 |
|---|---|
| 🐣 はじめのいっぽ | 最初のコミット |
| 🔥 ほのおのトレーナー | 7日連続コミット |
| 🏔️ やまのぬし | レベル10到達 |
| 📚 ずかんコレクター | ポケモン50匹ゲット |
| 🤝 なかまおもい | 10回レビュー |
| 👑 チャンピオン | 月間ランキング1位 |
| 🌟 でんせつ | Legendaryポケモンゲット |

## 優先度マトリクス

| | 実装コスト低 | 実装コスト高 |
|---|---|---|
| **効果大** | ストリーク, アチーブメント, レアリティ | バトル, レイド, Slack連携 |
| **効果中** | デイリーチャレンジ, パートナー, バッジ生成 | 交換, 進化, シーズン制 |
| **効果小** | プロフィールカスタム | グローバルランキング |

## 推奨実装順序

1. **Phase 1.1** コミットストリーク ← 最優先。コスト低・効果大
2. **Phase 2.1** レアリティシステム ← ポケモンの面白さ倍増
3. **Phase 4.3** アチーブメントシステム ← 目標ができる
4. **Phase 2.4** パートナーポケモン ← 愛着が生まれる
5. **Phase 1.2** デイリーチャレンジ ← 毎日の理由
6. **Phase 4.1** Slack/Discord連携 ← チームでの盛り上がり
7. **Phase 3.1** バトルシステム ← 長期エンゲージメント
8. **Phase 3.3** チームレイドイベント ← 最高の協力体験
